# 01 Profil Sistem

Folder ini menampung dokumen referensi sistem yang relatif stabil dan berlaku aktif.

## Isi Minimum Saat Ini

- `PROJECT_STATUS.md` untuk snapshot kondisi repo, scope aktif, dan status bootstrap
- `STACK_DAN_BASELINE.md` untuk baseline stack, asumsi teknis, dan guardrail awal Laravel 13

## Aturan

- dokumen di sini harus jujur membedakan mana yang sudah berjalan dan mana yang masih rencana
- jika ada keputusan baru yang menimpa substansi dokumen profil sistem, clause aktif yang relevan wajib ditarik ke keputusan baru
- dokumen profil sistem lama yang sudah tidak akurat jangan dipoles diam-diam bila perubahan bersifat normatif besar; gunakan lifecycle keputusan bila memang perlu
