## Temuan

### 1. Generate NIKC legacy masih hidup — DRIFT
- `app/Actions/ApproveRegistrationAction.php` masih mengeksekusi `$nikc = "KC-" . $tahun . "." . $matraCode . "." . $randomReg;`.
- Langsung melanggar `Kep.003` klausul 1 dan 2: NIKC permanen, sistem tidak boleh generate.
- Dampak: approval pendaftaran masih bisa “membangkitkan” NIKC baru.

### 2. Label dan pesan sistem masih menyebut `NIK`, bukan `NIKC` — DRIFT
- `ApproveRegistrationAction.php`: “login menggunakan NIK”.
- `VerificationController.php`: “login menggunakan NIK”.
- `Auth/Register.vue`: label `Username / NIK` di beberapa tempat.
- `Kep.009` mengidentifier login sebagai `NIKC atau username`.
- Dampak: pengguna salah paham identifier login.

### 3. Validasi NIKC belum seluruhnya via `NikcFormatRule` — PARSIAL
- `RegisterPersonelRequest` dan beberapa controller masih memakai `required|string|max:255` tanpa rule khusus.
- `NikcFormatRule` ada, tapi cross-cutting enforcement-nya belum sempurna.
- Dampak: NIKC bisa lolos dengan format salah di jalur yang tidak tercover.

### 4. Input `province` masih text bebas — PARSIAL
- `Auth/Register.vue`: input `province` berupa text field biasa.
- `Kep.003` mengizinkan reuse `province`, tetapi reuse tidak berarti tetap bebas input.
- Dampak: user bisa input “Jabar” atau nama provinsi bebas, melenceng dari kode 01–34.

### 5. Fallback hard-coded NIKC di export — RISIKO
- `PersonelExport.php` dan `BroadcastResponseExport.php` menyimpan default `$signerNikc = '12000018012200216'`.
- Dampak: laporan bisa menampilkan NIKC palsu jika data aktual kosong.

### 6. Route publik SKEP tanpa batas eksplisit — KEBERADAAN
- `routes/web.php`: `GET /skep/check` ke `SkepPublicController::checkNikc`.
- `Kep.003` tidak membahas batas akses publik SKEP, jadi ini bukan drift normatif langsung.
- Dampak: access boundary belum normatif; perlu keputusan turunan atau workplan jika domain SKEP diperluas.

### 7. Family naming drift `2026.02.002` vs `YYYY.Kep.XXX` — DRIFT DOKUMEN
- `2026.02.002 tentang Standar UI dan Design System Kctrimatra.md` masih memakai format lama.
- Semua keputusan lain sudah dinormalisasi ke `YYYY.Kep.XXX`.
- Dampak: inkonsistensi identitas dokumen aktif, menyalahi `Kep.001`.

### 8. `Kep.009`/`010`/`011` belum punya `Changelog Dokumen` — KURANG
- `Kep.009`, `Kep.010`, `Kep.011` tidak memiliki blok `## Changelog Dokumen`.
- Dampak: jejak audit formal perubahan internal belum lengkap.

### 9. Path metadata tidak seragam — DRIFT DOKUMEN
- Beberapa keputusan menulis path eksplisit `docs/02 Keputusan/...`, yang lain tanpa `docs/`.
- Dampak: merusak konsistensi styling lintas dokumen.

### 10. Drift UI/UX terhadap `2026.02.002` — DRIFT UI
- `AuthenticatedLayout.vue`, `GuestLayout.vue`, `PrimaryButton.vue`, `SecondaryButton.vue`, `Login.vue`, `Admin/Personel/Index.vue`, `Admin/Dashboard.vue`
- Masih memakai palette biru Slate/Indigo (`#2563EB`, `#E2E8F0`), bukan hijau militer sesuai `2026.02.002`.
- `tailwind.config.js` masih `Figtree`, bukan `IBM Plex Sans`.
- Dampak: seluruh chrome dan komponen UI drift dari standar desain yang sudah ditetapkan.

## Dampak Gabungan

1. Norma NIKC yang sudah final tidak sepenuhnya dijalankan di runtime.
2. Pengguna dapat mengalami kebingungan identifier login dan input form.
3. Dokumentasi repo mengalami inkonsistensi family naming, metadata, dan changelog.
4. UI/UX repo tidak sesuai standar design system yang sudah ditetapkan.
5. Beberapa aspek implementasi mengklaim “selesai” di changelog/workplan, tetapi audit read-only menunjukkan sisa drift yang cukup berarti.
