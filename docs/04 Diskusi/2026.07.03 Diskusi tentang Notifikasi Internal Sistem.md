## Pemicu

Bahan user memuat kebutuhan notifikasi internal untuk proses seperti klaim akun dan pengajuan KTA. Karena notifikasi adalah kemampuan lintas modul, perlu diskusi tersendiri agar tidak tersebar sebagai detail sampingan di banyak domain.

## Temuan Awal

- notifikasi bergantung pada keputusan di domain akun dan layanan anggota
- belum ada keputusan apakah sistem hanya memakai in-app notification atau juga kanal lain
- topik ini bukan fondasi paling awal, tetapi perlu dicatat sekarang agar event lintas modul tidak tercecer

### Kondisi kode aktual

- notifikasi in-app sudah berjalan berbasis database notification Laravel
- ada halaman inbox notifikasi, aksi tandai baca, dan tandai semua dibaca
- event notifikasi sudah dipakai untuk broadcast kegiatan baru
- payload notifikasi sudah memuat judul, pesan, ikon, dan URL tujuan
- penggunaan notifikasi ini sudah menyeberang ke modul lain, terutama broadcast dan persetujuan akun

## Poin Diskusi

### 1. Kanal notifikasi

Perlu diputuskan apakah notifikasi hanya hidup di dalam aplikasi atau melibatkan email atau kanal lain.

### 2. Event notifikasi

Perlu didaftar event minimum yang memang penting untuk user dan pengelola.

### 3. Status baca dan penyajian

Perlu dibahas apakah notifikasi disimpan sebagai histori dan bagaimana status bacanya dikelola.

### 4. Event minimum sudah mulai muncul di kode

Kode aktual sudah memberi sinyal event minimum yang mungkin perlu dibakukan:

- notifikasi penerbitan broadcast baru
- notifikasi tindak lanjut persetujuan atau penolakan akun
- notifikasi tindakan sistem yang perlu dibaca user

## Catatan untuk AI Agent

- jangan turunkan topik ini ke tabel, event class, atau UI lonceng sebelum proses bisnis pemicunya stabil
- sinkronkan dengan diskusi akun dan KTA yang kemungkinan paling awal membutuhkan notifikasi
- gunakan diskusi ini untuk memutuskan event minimum sebelum menambah kanal baru

## Pertanyaan Terbuka

- apakah notifikasi hanya in-app
- event apa saja yang wajib ada pada fase awal
- apakah notifikasi yang sudah dibaca tetap disimpan
- apakah notifikasi broadcast dan persetujuan akun termasuk scope awal
