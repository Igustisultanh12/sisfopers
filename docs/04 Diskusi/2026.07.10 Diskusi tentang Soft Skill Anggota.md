## Pemicu

User menambahkan kebutuhan operasional baru yang dipakai untuk validasi kegiatan dan kebutuhan administrasi lain. Domain ini belum memiliki rumah diskusi aktif, tetapi sudah cukup jelas untuk dibahas terpisah dari biodata inti agar tidak bercampur dengan alamat, kontak, atau SINYALEMEN.

## Temuan Awal

- belum ada file aktif khusus untuk soft skill anggota
- belum ada implementasi aktif untuk kategori, sub-kategori, atau master skill
- belum ada alur usulan skill baru oleh anggota
- belum ada aturan final untuk sertifikat, lembaga penerbit, atau masa berlaku

Catatan field:

- sub-kategori bersifat opsional
- satu skill tidak dibuka untuk lebih dari satu kategori pada fase awal kecuali nanti diputuskan berbeda
- skill bahasa adalah subset dari soft skill, bukan domain terpisah
- setiap skill wajib punya bukti sertifikat dan lembaga penerbit
- status aktif/nonaktif dipakai untuk arsip data master tanpa menghapus histori

## Klarifikasi dari User

- soft skill memiliki hierarki fleksibel: Kategori Utama -> Sub-Kategori opsional -> Skill
- hanya Super Admin yang bisa membuat Kategori dan Skill baru
- anggota bisa mengusulkan skill baru, lalu Super Admin yang menyetujui atau menolak
- skill bahasa adalah bagian dari soft skill
- skill bahasa memiliki data tambahan seperti lembaga tes, jenis tes, skor, dan tanggal kadaluarsa
- setiap skill wajib dibuktikan dengan sertifikat dan lembaga penerbit wajib dicatat
- tanda tangan masih di-hold dan tidak dicampur ke domain ini
- CEFR boleh dicatat bila relevan untuk bahasa Eropa atau setara
- satu bahasa dapat memiliki lebih dari satu bukti tes bila nanti diputuskan boleh
- sertifikat kadaluarsa perlu ditegaskan status validitasnya saat dipakai untuk kegiatan

## Poin Diskusi

### 1. Hierarki soft skill

Perlu diputuskan apakah:

- sub-kategori selalu opsional
- satu skill boleh berada di lebih dari satu kategori atau hanya satu
- kategori utama boleh langsung menampung skill tanpa sub-kategori

### 2. Skill bahasa sebagai subset soft skill

Perlu diputuskan atribut tambahan apa yang wajib dicatat untuk skill bahasa, termasuk:

- lembaga tes
- jenis tes
- skor atau level
- level CEFR bila relevan
- tanggal sertifikat
- tanggal kadaluarsa
- file bukti sertifikat

### 3. Usulan skill oleh anggota

Perlu diputuskan alur usulan:

- apakah anggota bisa mengusulkan skill baru dari profilnya
- apakah skill yang disetujui langsung menempel ke profil anggota atau perlu ditambahkan lagi
- apakah usulan yang ditolak boleh diajukan ulang
- apakah skill yang disetujui otomatis menempel ke personel pengusul atau menunggu aksi tambah manual

### 4. Sertifikat dan validasi

Perlu diputuskan apakah sertifikat yang kadaluarsa otomatis tidak valid untuk validasi kegiatan, atau masih bisa dipakai dengan batas tertentu.

## Catatan untuk AI Agent

- jangan lahirkan master data atau schema soft skill sebelum scope dan hierarki disepakati
- skill bahasa tetap berada dalam rumpun soft skill, bukan domain terpisah
- setiap keputusan nanti harus bisa dipakai untuk validasi kegiatan tanpa membuat duplikasi field dengan biodata inti
- bila struktur final banyak, turunkan ke rencana kerja setelah keputusan lahir

## Pertanyaan Terbuka

- apakah sub-kategori selalu opsional
- apakah satu skill hanya boleh dimiliki satu kategori
- apakah sertifikat kadaluarsa otomatis tidak valid
- apakah anggota yang mengusulkan skill langsung bisa memilikinya setelah disetujui
- apakah level CEFR perlu dicatat untuk skill bahasa tertentu
