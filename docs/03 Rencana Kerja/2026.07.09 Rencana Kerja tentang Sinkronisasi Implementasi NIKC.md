## Tujuan

- menghentikan generate NIKC baru dari alur approval
- menyelaraskan registrasi, admin, dan verifikasi dengan NIKC permanen
- menyiapkan master_kepangkatan dan master_provinsi sebagai sumber data referensi
- menggunakan ulang field `province` bila maknanya sama dengan provinsi Latsarmil
- mengubah UI `province` menjadi pilihan data yang jelas dan dapat dicari
- memastikan alur yang belum ada di sistem tetap out-of-scope dan tidak masuk implementasi ini
- menormalisasi label, pesan, dan validasi form publik sesuai diskusi
- menambahkan verifikasi publik 2 faktor NIKC + tanggal lahir untuk mencegah brute force
- menyediakan tabel konversi `master_provinsi` untuk validasi digit 16–17 NIKC sesuai kode Latsarmil

## Kondisi Stop

Hentikan pekerjaan jika:
- keputusan sumber tidak ditemukan atau isinya bertentangan dengan workplan ini
- kode aktual masih mengandung alur generate NIKC baru yang belum terpetakan jelas
- perubahan yang dibutuhkan ternyata mengharuskan penghapusan data atau perubahan destruktif tanpa konfirmasi user
- ada kebutuhan untuk menghidupkan kembali scope `NIKC belum ada di sistem`, `pending verifikasi`, atau unggah PDF keputusan di workplan ini
- perubahan teknis berpotensi memecah makna field `province` tanpa keputusan eksplisit
- repo aktual menunjukkan drift baru yang belum dicatat di diskusi atau keputusan
- diperlukan normalisasi massal data existing tanpa mekanisme per-record

## Fase 0 - Validasi NIKC 17 Digit Global

### Tujuan
Menegakkan validasi `digits:17|numeric|unique` pada seluruh titik input NIKC di backend.

### Klasifikasi
- reversible

### File yang disentuh
- `app/Http/Requests/Auth/RegisterPersonelRequest.php`
- `app/Http/Controllers/Auth/AuthController.php`
- `app/Http/Controllers/Admin/MasterPersonelController.php`
- `app/Http/Controllers/SkepPublicController.php`
- `app/Http/Controllers/Admin/SkepController.php`
- `app/Http/Controllers/Admin/VerificationController.php`

### Verifikasi fase
- pastikan setiap request yang menerima `nikc` menggunakan rule `required|digits:17|numeric|unique:personels,nikc` atau `nullable|digits:17|numeric` sesuai konteks
- pastikan tidak ada `string|max:255` yang menampung NIKC lagi
- jalankan `php -l` pada file PHP yang disentuh

### Langkah jika gagal
- kembalikan perubahan fase ini sebelum melanjutkan fase berikutnya
- catat gap-nya di workplan sebelum mencoba jalur lain

### Status Fase
- Selesai pada 20 Juli 2026.
- Ditambahkan `app/Rules/NikcFormatRule.php`.
- Rule memvalidasi NIKC tepat 17 digit angka, digit kelompok kepangkatan, digit matra, nomor registrasi, bulan/tahun lahir, dan kode provinsi Latsarmil aktif dari `master_provinsi`.
- Rule dapat mencocokkan bulan/tahun NIKC dengan DOB saat DOB tersedia.
- Rule dapat mencocokkan digit 16-17 NIKC dengan `province` saat nama provinsi tersedia.
- Rule dipakai pada `RegisterPersonelRequest`, `AuthController`, `SkepPublicController`, `MasterPersonelController`, dan import `SkepController`.

### Status Fase
- Selesai pada 20 Juli 2026.
- Ditambahkan migration DOB pada `skep_data` dan `skep_requests`.
- `SkepPublicController::checkNikc` mewajibkan `nikc + dob`, mencocokkan DOB ke `personels.dob` atau `skep_data.dob`, dan memakai rate-limit 3 percobaan per 6 jam per IP.
- `SkepPublicController::submitRequest` mewajibkan DOB dan menyimpannya pada pengajuan SKEP.
- Import SKEP admin sekarang mensyaratkan kolom Tanggal Lahir dan menyimpan DOB ke `skep_data`.
- Approval SKEP web dan API menyalin DOB dari `skep_requests` ke `skep_data`.
- `AuthController::register` menolak submit register bila DOB tidak cocok dengan DOB pada database SKEP untuk NIKC tersebut.
- Register publik meminta DOB sebelum pengecekan NIKC dan mengirim `dob` ke `/skep/check`.
- Admin SKEP menampilkan DOB dan memperbarui panduan format kolom import Excel.

### Status Fase
- Selesai pada 20 Juli 2026.
- `PersonelExport` dan `BroadcastResponseExport` tidak lagi memakai nama, pangkat, NIKC, dan jabatan penandatangan hardcoded.

### Status Fase
