## Latar Belakang
Diskusi `2026.07.03 Diskusi tentang Riwayat Pendidikan dan Diklat Anggota` telah difinalkan (`[SELESAI]` di `00 Arsip`). Riwayat pendidikan memisahkan tiga rumpun: akademik (sumber gelar), diklat (sertifikat, tak ber-gelar), dan militer (latsarmil, bukti keanggotaan). Keputusan ini mengunci struktur, CRUD, visibilitas, dan pemisahan Ijazah Latsarmil vs SK Penetapan.

## Keputusan
1. **Tiga rumpun pendidikan** (`jenis`):
   - **AKADEMIK** = pendidikan umum/formal (SD s.d. S3/D4/Profesi). Sumber suffix gelar (Kep.011). Gelar profesi (`dr.`/`Ir.`/`Apt.`) lahir dari pendidikan profesi/umum, BUKAN diklat.
   - **DIKLAT** = kursus/sertifikasi umum (tak ber-gelar). Ikut diklat BELUM TENTU punya sertifikat; sertifikat hasil ujian (TOEFL/IELTS/dll) = Soft Skill (Kep.010 / #10), BUKAN entri DIKLAT.
   - **MILITER** = Latsarmil. Bukti keanggotaan & dasar hak grup baru (Kep.004 klausul 24).
2. **Tabel `riwayat_pendidikan`** (one-to-many, FK `personel_id`): `jenjang` (enum SD/SMP/SMA/D3/D4/S1/S2/S3/PROFESI/LAIN), `program_studi` (free-text), `nama_institusi`/`penyelenggara`, `tahun_lulus`, `file_ijazah_path`/`file_sertifikat_path`, `nomor_ijazah`, `sk_penetapan_id` (nullable, hanya entri terkait SK), `verified_at`, `verified_by`, `deleted_at`. Menggantikan `education_*` single-row di `personels`.
3. **Ijazah Latsarmil ≠ SK Penetapan:** Ijazah Latsarmil = dokumen INDIVIDU 1 nama, personel unggah sendiri (entri `jenis=MILITER`). SK Penetapan = dokumen SHARED multi-nama; Super Admin unggah langsung dipakai sistem, personel unggah → `PENDING_TMP` (Kep.007) nunggu verifikasi admin.
4. **CRUD:** HANYA personel/Super Admin yang input; koordinator HANYA verifikasi (tidak input). Tambah = draft + upload bukti; Ubah = data belum terkunci atau via ajuan koreksi; Hapus = soft-delete. Jika AKADEMIK diubah/hapus, suffix gelar (Kep.011) di-recompute.
5. **Visibilitas:** Super Admin lihat semua; koordinator hanya biodata umum + dokumen diverifikasi (Kep.007); personel hanya diri sendiri.
6. **Tidak perlu `expires_at`** (pendidikan/ijazah tak kadaluarsa; sertifikat kadaluarsa di #10 Soft Skill).
7. **Anti-duplikat:** unique `(personel_id, jenis, jenjang, program_studi, tahun_lulus)` untuk akademik/diklat; `(personel_id, nomor_ijazah)` untuk militer.
8. **Kontrak parse SK** (untuk Kep.010): pola "`<JENJANG> <PROGRAM>`" → `jenjang`=token pertama, `program_studi`=sisa. Gagal parse → `jenjang=LAIN` + flag review.
