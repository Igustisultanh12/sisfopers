## Latar Belakang
Diskusi `2026.07.09 Diskusi tentang Format Nama Lengkap dengan Prefix Pangkat dan Suffix Gelar Pendidikan` telah difinalkan (`[SELESAI]` di `00 Arsip`). Format nama terdiri dari prefix pangkat + nama lengkap + suffix gelar. Keputusan ini mengunci rumus display dan aturan gelar.

## Keputusan
1. **Rumus display (target implementasi):** `FORMAT_FINAL = PREFIX_PANGKAT [ + FRONT_TITLE ] + SPASI + full_name + SPASI + SUFFIX_GELAR`.
   - `full_name` = satu kolom plain (sudah ada di `personels`). Belum ada `display_name`/`formatName` di kode → pekerjaan implementasi.
   - `PREFIX_PANGKAT` dari Kep.005 (termasuk `(W)` gender). 3 pangkat klaim: Prada KC / Serda KC / Letda KC.
2. **Suffix gelar:** dihitung otomatis dari riwayat pendidikan AKADEMIK (Kep.008), urut S1→S2→S3, dipisah koma+spasi. String diambil apa adanya dari calon (free-text, tidak divalidasi; ijazah = bukti).
3. **Front title:** HANYA jika (a) ada sertifikat profesi/ijazah akademik, DAN (b) gelar = pendidikan umum/akademik. Dimasukkan: `dr.`(dokter), `Ir.`(insinyur), `Apt.`(apoteker). Dikeluarkan: `H.`/`Hj.`/`Ky.` (keagamaan, bukan akademik). `dr.`(depan) ≠ `Dr.`(suffix S3).
4. **Gelar melekat pada pendidikan umum/akademik** (harus dibuktikan ijazah). Jika SK sudah ada gelar → tidak wajib upload ijazah; edit profil mau nyantumkan gelar → wajib upload ijazah.
5. **Pemisahan:** Ijazah Akademik (sumber gelar, Kep.008) ≠ Ijazah Latsarmil (bukti keanggotaan, Kep.009 T3). Diklat bahasa ≠ sertifikat bahasa (Soft Skill #10).
6. **OCR:** #10 (Kep.010) cukup strip gelar depan/belakang saat match; Kep.011 cukup definisikan canonical.
