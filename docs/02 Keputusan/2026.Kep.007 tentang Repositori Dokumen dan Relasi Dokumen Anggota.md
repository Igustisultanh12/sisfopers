## Latar Belakang
Diskusi `2026.07.03 Diskusi tentang Repositori Dokumen dan Relasi Dokumen Anggota` telah difinalkan (`[SELESAI]` di `00 Arsip`). Sistem menyimpan dokumen yang diunggah anggota dan admin, bukan membuat surat keluar. Keputusan ini mengunci istilah, klasifikasi, relasi many-to-many, lifecycle, dan pemisahan dua lapis repositori.

## Keputusan
1. **Dua lapis repositori (rumah berbeda):**
   - (A) Repositori Regulasi Hukum = `docs/10 Referensi Internal/` (sudah final, arsip 2026.07.10 + Kep.001 klausul 14). Taxonomy: Undang-Undang / Peraturan / Peraturan Menteri / Keputusan Menteri / Edaran / Lainnya. PDF sumber wajib di repo (`docs/`), bukan storage app. Surat Keputusan hidup di rumpun `Keputusan Menteri`.
   - (B) Repositori Dokumen Personel/Operasional = storage app: KTP, ijazah, foto profil, sertifikat, softcopy SK operasional (`surat-keputusan/`). Ini ranah keputusan ini.
   - SK Penetapan = jembatan: secara hukum masuk (A) rumpun Keputusan Menteri; secara operasional softcopy-nya masuk (B) + tabel `surat_keputusan_artifacts`/`_entries`. Keduanya rujuk nomor SK sama.
2. **Istilah:** `dokumen` = payung untuk semua file terunggah (KTP, ijazah, SK, sertifikat, foto). `surat` / Surat Keputusan (SK) = subset dokumen yang bersifat keputusan resmi (multi-nama, bersama). Klasifikasi `jenis_dokumen`: `KTP`, `IJAZAH_AKADEMIK`, `IJAZAH_LATARMIL`, `SK_PENETAPAN`, `SERTIFIKAT` (diklat/soft skill), `FOTO_PROFIL`.
3. **Relasi many-to-many:** SK Penetapan = 1 dokumen → banyak personel (sudah ada `surat_keputusan_personel_entries`). Ijazah/KTP/Sertifikat = 1 dokumen → 1 personel (di `personels`/`riwayat_pendidikan`). Tabel `dokumen_anggota` (generic pivot) hanya bila kelak dokumen non-SK perlu dibagikan; fase awal cukup `surat_keputusan_personel_entries` + field personel/riwayat.
4. **Lifecycle status:** `PENDING_TMP` (unggah personel, belum diverifikasi), `AKTIF`, `DITOLAK`, `KADALUARSA` (hanya sertifikat berlaku terbatas, lihat Kep.010/Soft Skill), `SOFT_DELETED`. SK Penetapan yang berlaku = nomor sama & tanggal terbaru. Soft-delete wajib (tidak hard-delete) agar audit trail terjaga.
5. **PENDING_TMP = STATUS FLAG, bukan folder fisik:** personel unggah SK → `status = PENDING_TMP`; admin verifikasi → `AKTIF`.
6. **Visibilitas:** Super Admin lihat semua; koordinator hanya biodata umum + dokumen yang sedang diverifikasinya (tidak boleh browsing semua); personel hanya diri sendiri (selaras Kep.006 + 2026.11.004).
7. **Keamanan & privasi (turunan ke 03 Rencana Kerja, bukan implementasi di sini):** dokumen pribadi TIDAK di disk `public`; simpan di disk `private`/`local`, akses via route berproteksi + `response()->file()` berotorisasi. Tambah `document_access_logs` (siapa akses dokumen apa+kapan). Enkripsi at rest untuk kolom path sensitif. Retensi/right-to-erasure ditetapkan di 03 Rencana Kerja. KTP berlaku seumur hidup (status KADALUARSA TIDAK dipakai untuk KTP).
