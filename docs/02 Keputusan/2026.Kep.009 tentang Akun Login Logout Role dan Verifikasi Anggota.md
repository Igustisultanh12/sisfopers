## Keputusan
1. **Login identifier:** NIKC (17 digit) atau username. **NIK (16 digit) BUKAN identifier login** — hanya untuk profil internal personel (pencocokan data, OCR KTP → `personels.nik`). Super Admin non-Komcad login via username (tidak punya NIKC).
2. **Role:** 4 role operasional (personel, koordinator, wakil koordinator, admin) + Super Admin sebagai hak administratif tertinggi (Kep.006). `admin` = daily-term untuk Super Admin; hak ini dapat melekat pada personel Komcad penuh, sementara pengecualian non-Komcad tetap mengikuti Kep.006 bila memang diperlukan.
3. **Pola aktivasi:** model hibrida — admin boleh membuat akun, registrasi mandiri NIKC-first juga boleh berjalan sebagai PENDING. Jika NIKC belum ada di sistem → cabang upload-SK (berat) ATAU upload Ijazah Latsarmil (ringan, opsional) sebagai bukti keanggotaan → tetap PENDING (Kep.008).
4. **Verifikasi:** gating `is_active`. Koordinator memverifikasi dokumen hilang (KTA/Ijazah); admin memverifikasi sisanya (termasuk SK penetapan/bukti keanggotaan). Koordinator hanya untuk klaim awal, bukan update data berkala.
5. **KYC Pengajuan & Swafoto Pengajuan:** proses + artefak pembuktian SIAPA yang mengajukan saat registrasi. WAJIB secara keputusan, BELUM aktif di kode (dead middleware `EnsureFaceVerified` → rename `EnsureKycSubmitted`). Bukan verifikasi wajah/face recognition. Face Recognition otomatis = HOLD (Kep.004).
6. **MFA (2FA):** status HOLD. Fitur PENTING yang dipertahankan, cukup yatim/dormant (field & route tetap ada, tak direachable, tak dipakai hingga keputusan baru). Tidak dihapus.
7. **Super Admin non-Komcad:** dikelola via dashboard oleh Super Admin lain (Kep.006 klausul 16-20). Identifier NRP (eks Komponen Utama) atau NIK (bukan Komponen Utama). `nikc` nullable. Personel Komcad penuh juga dapat memegang hak Super Admin dan tetap menggunakan NIKC.
8. **Abituren:** Reguler/ASN/SPPI semua boleh daftar. NIKC kode 3 boleh milik Letda (SPPI) selama NIKC tetap 3 (Kep.003).
