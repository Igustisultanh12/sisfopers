# 11 Referensi Teknis

Folder ini berisi panduan teknis, template implementatif, blueprint, dan referensi turunan yang menjabarkan keputusan aktif.

## Aturan

- dokumen di sini tidak boleh menjadi sumber keputusan normatif utama
- referensi teknis baru hanya boleh lahir setelah ada keputusan final yang menjadi landasannya atau instruksi eksplisit user
- nama file aktif baru wajib mengikuti format `YYYY.11.XXX tentang Judul Dokumen.md`
- jika keputusan yang menjadi dasar dicabut, referensi teknis terkait wajib diaudit
