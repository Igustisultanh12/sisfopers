## Posisi

Dokumen ini bukan keputusan normatif. Referensi ini hanya menjelaskan kebutuhan runtime agar implementasi OCR di repo `kctrimatra` bisa hidup di local maupun hosting.

## Binary yang Dibutuhkan

- `pdftotext`: membaca PDF berlapis teks.
- `pdftoppm`: mengubah halaman PDF scan menjadi gambar.
- `tesseract`: membaca teks dari gambar.
- `tessdata` bahasa: minimal `ind.traineddata` dan `eng.traineddata` bila memakai `OCR_TESSERACT_LANG=ind+eng`.

## Konfigurasi `.env`

```env
OCR_PDFTOTEXT_PATH=pdftotext
OCR_PDFTOPPM_PATH=pdftoppm
OCR_TESSERACT_PATH=tesseract
OCR_TESSERACT_LANG=ind+eng
OCR_TIMEOUT=120
OCR_MAX_PDF_OCR_PAGES=5
```

Pada shared hosting yang tidak menyediakan binary global, arahkan path ke binary lokal akun hosting, misalnya:

```env
OCR_TESSERACT_PATH=/home/USER/tesseract_local/tesseract
OCR_PDFTOPPM_PATH=/home/USER/poppler_local/bin/pdftoppm
OCR_PDFTOTEXT_PATH=/home/USER/poppler_local/bin/pdftotext
```

## Catatan Implementasi Repo

- OCR adalah alat bantu, bukan otoritas; hasilnya wajib direview admin/koordinator sesuai `2026.Kep.010`.
- Jika binary tidak tersedia, job OCR dokumen boleh gagal ke status `FAILED` tanpa menggagalkan registrasi atau upload dokumen utama.
- SK massal diproses sebagai structured import/PDF text layer lebih dulu, bukan OCR gambar sebagai jalur utama.
- KTP/ijazah/sertifikat memakai OCR gambar/PDF sebagai bahan bantu verifikasi, menyimpan hasil teks di disk private.
