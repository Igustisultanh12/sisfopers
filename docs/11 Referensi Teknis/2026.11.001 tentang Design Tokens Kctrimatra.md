## Tujuan

Dokumen ini menjabarkan token teknis yang menurunkan keputusan UI aktif ke bahasa implementasi yang dapat dipakai lintas CSS, Blade, atau frontend stack yang nanti dipilih.

## Prinsip

- token sistem dipakai untuk seluruh chrome aplikasi
- token matra dipakai hanya untuk elemen kontekstual domain
- token semantik sistem dipisahkan dari token matra
- `IBM Plex Sans` menjadi font sans utama awal
- warna yang belum punya kebutuhan operasional nyata tidak perlu dipaksakan hidup sejak fase awal

## Aturan Pakai

- token matra tidak dipakai untuk tombol primer sistem, sidebar, topbar, background halaman penuh, atau focus ring global
- token matra dipakai hanya pada badge matra, filter matra, edge kartu, avatar ring, atau dokumen identitas yang memang perlu penanda matra
- status keanggotaan memakai token semantik sistem, bukan token matra
- warna Mabes atau gabungan belum dibakukan pada fase awal; ia hanya boleh lahir setelah ada kebutuhan operasional yang nyata
- jika stack frontend berubah, nama variabel boleh disesuaikan selama makna token dan hirarki normatif keputusan tetap dipertahankan
